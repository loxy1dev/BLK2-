# TXT Vault — Premium Vercel

Version premium/dark du viewer de fichiers TXT.

Ajoute tes fichiers TXT dans `public/stock/`. Le bouton sélectionne aléatoirement un fichier et affiche deux liens publics vers celui-ci.

## Déploiement
1. `npm install`
2. `npm run dev` pour tester localement
3. Mets le projet sur GitHub
4. Importe le dépôt dans Vercel

Les fichiers de démonstration sont fictifs.
